# pi-ask-user-async

Pi のエージェントが選択肢付きの質問を行う extension です。選択肢に加えて自由入力もできます。回答を待つ同期モードと、独立した作業を続けられる非同期モードを備えています。

## インストール

GitHub から Pi パッケージとしてインストールできます。

```sh
pi install git:github.com/tesso57/ask
```

ローカルで試す場合は、このディレクトリで次を実行します。

```sh
pi -e ./extensions/ask.ts
```

確認した環境は Pi 1.5.0 です。Pi の extension として動作し、通常のユーザー入力の代わりに自動で起動するものではありません。モデルが `ask_user` ツールを呼ぶと質問が表示されます。

## 使い方

エージェントに、必要なときは選択肢付きで質問するよう伝えてください。

- **async**: 質問を回答待ちとして表示し、ツールはすぐに戻ります。エージェントは回答に依存しない作業を続けられます。ユーザーは `/answer 1` のように表示された番号を指定して回答します。実行中の回答は次の機会にエージェントへ伝わり、待機中の回答は新しいターンを開始します。
- **sync**: 選択または自由入力を待ってからツールが戻ります。作業の続行に回答が必須の場合に使います。

Escape または空の自由入力は未回答として扱います。非同期の質問はセッション切り替え、履歴ツリーの移動、再読み込み、再起動で消えます。print/JSON モードなど UI のない環境では、質問できない旨を返します。RPC クライアントでは通知、ウィジェット、コマンド、選択ダイアログへの対応が必要です。

非同期で独立した作業を続けること、回答が必要な作業を待つことはモデルへの指示に依存します。extension 自体が後続の操作を強制的に制御するものではありません。

## 開発

Node.js 22.18 以降で `npm install` の後、`npm test` を実行します。
